# Карточка находки и журнал триажа

| Поле | Что записывать |
| --- | --- |
| ID и контур | Идентификатор правила и источник `model` или `wrapper` |
| Объект | Файл, строка, пакет и версия либо имя тензора |
| Доказательство | Наблюдаемый признак и способ воспроизведения |
| Серьёзность | `critical`, `high`, `medium` или `low` |
| Статус | `needs_review`, `confirmed`, `false_positive` или `fixed` |
| Решение | Основание статуса и следующий шаг |

## Примеры из синтетического стенда

Полный результат локального запуска доступен в [report.json](../report.json).

| Правило | Доказательство | Статус на стенде | Решение |
| --- | --- | --- | --- |
| `MDL-PICKLE-RCE` | В `infected_checkpoint.pt`, внутри `archive/data.pkl`, статический разбор обнаружил `STACK_GLOBAL` для `builtins.eval` на смещении 18. | Подтверждено | Заблокировать загрузку checkpoint и взять веса из доверенного источника. |
| `MDL-BACKDOOR-NEURON` | L2-норма строки №3 тензора `backbone.fc1.weight` в 55,4 раза выше медианы слоя. Аномалию добавили при генерации стенда. | Подтверждено на синтетических данных | Для незнакомой модели зафиксировать подозрение и проверить происхождение весов и поведение на триггерах. |
| `WRP-RCE-EVAL` | В `service.py:17` переданный пользователем `user_expr` попадает в `eval()`. | Подтверждено | Разбирать вход как число и проверить диапазон. |
| `WRP-CMD-SUBPROCESS-SHELL` | В `service.py:18` команда содержит `image_path` и выполняется с `shell=True`. | Подтверждено | Передавать проверенные аргументы списком и запускать команду без оболочки. |
| `MDL-BACKDOOR-BIAS` | Смещение класса №7 в `classifier.head.bias` равно 8,95 при среднем остальных классов −0,0056. | Подтверждено на синтетических данных | Сверить с доверенной версией модели и проверить поведение целевого класса. |
| `MDL-HF-AUTOMAP` | В `config.json` указан класс `modeling_custom.CustomClassifier` в `auto_map`. | Подтверждено | Проверить происхождение класса и держать `trust_remote_code` выключенным для недоверенного кода. |
| `MDL-DEP-CVE-2025-32434` | Офлайн-база сопоставила запись `torch==2.1.0` в `requirements.txt:2` с CVE-2025-32434. | Подтверждено на стенде | Сверить установленную версию с бюллетенем и выбрать исправленную версию. |
| `WRP-ML-TORCHLOAD` | В `service.py:11` вызывается `torch.load(model_path)` без явного `weights_only=True`. | Подтверждено | Использовать проверенный формат весов и зафиксировать безопасную версию загрузчика. |
| `WRP-SECRET-001` | В `service.py:8` значение `HF_API_TOKEN` задано прямо в исходнике. В стенде используется синтетический токен. | Подтверждено на стенде | Получать токен из секрета окружения. Для настоящего токена также нужна ротация. |

Эти статусы относятся к синтетическим данным. Для материалов организаторов заведите отдельные карточки и подтвердите каждую по её доказательству.
